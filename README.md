## 🎯 Motivation

The objective of this thesis is to develop a standardized, transparent, and practice-oriented methodology for forecast-based load estimation of new development areas in electrical distribution networks.


## 🛠️ Technologies Used

This simple UI was built using Streamlit.


## 💻 Usage

1. Clone the repository:
```
git clone https://github.com/nadabergaoui99-droid/netz_app.git
```
2. Install the required dependencies:

```
pip install -r requirements.txt
```
3. Go to the `NETZAPP` folder:

```
cd NETZAPP/

3. Run the app:
```
streamlit run Lastermittlung.py
```
4. Access the app in your browser at  
Local URL: http://localhost:8501
  Network URL: http://10.54.76.184:8501
